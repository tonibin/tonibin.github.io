Intro: what is cdd?

cdd is a UNIX tool, written in bash, that operates on a text file cd database for extracting information and data and reporting all in a pretty format. The program has various options to control its behavior, and may be customizable to some extent.
The package contains the following files:
  • cdd, the main script
  • add2cdd, a cdd utility
  • custom.data, contains some customizable data
  • peryear, a bash tool for extracting information ordered by years.
  • user manual.txt, a short reference manual
  • reformat, a bash tool to update databases made with former versions of cdd
A brief description. The database is formed by text lines, each containing six fields:
  • author
  • title
  • recording year
  • issue year (the actual date of the cd printing)
  • publisher
  • notes
All fields are separated by a special character (defined in custom.data): by default it's the vertical bar |. Here's an example:
led zeppelin|bbc sessions|v.v.|1997|tracks from studio and live|atlantic|
The format is quite unreadable, but it's pure text, and may be altered by any editor.

The simplest usage is cdd <pattern> (look out: all files must reside in the same directory) as in the following example:
$ cdd led
The output will be

led zeppelin    bbc sessions    v.v.    1997    from studio and live

(the database is all in lower letters, but you can use patterns in any character, since cdd in case-insensitive; also, the aligned format does not report the publisher's name). cdd has searched through the database and has reported all the lines containing the pattern "led" (it could have been in the title or in the notes, for example). Another useful usage is:
$ cdd -a
this command (-a option, no patterns) simply prints out the whole database in the default view ('a' stands for all). Here's what happens here:

bruce, jack          songs for a tailor          1969 1997       
dandy wharols        the dandy wharols           1996 1996   
led zeppelin         bbc sessions                v.v. 1997  from studio & li
pat metheny group    letter from home            1989 1989     
......
......

The default format is a fixed-size output; there are other two views: a plain format in which the separator (|) is changed into a TAB and a framed output. Now that you've understood the principles, here's the output of the -h options (h for help):

$ cdd -h
Usage: cdd [OPTIONS] pattern [+|- pattern2]
cdd prints all lines matching pattern (which may contain spaces). Options
([] indicates facultative arguments, while <> indicates mandatory arguments):
  -a           print all database
  --add [db]   call 'add2cdd [db]' for adding records to the [db] database
  -A           align output in fixed-size columns (may trim fields)
  -c           report total number of database records and exit
  -C           add number of found records to report
  -d <pat>     start deletion procedure over records matching pattern <pat>
  -f <file>    extract info from <file> rather than from cd.db
  -F           formatted output (may end in a long listing)
  -h --help    print this help and exit
  -l n         list last n added records from log file (10 if n is not valid)
  -L           list entire log file
  -m <pat>     start modifying procedure over records matching pattern <pat>
  -n           print record number for each output line (unformatted outputs)
  -N           print output in plain format (may give uneasy listing)
  -o <aryipn>  output selected field only, sorting and unifying identical lines
  -r           reverse sorting (see -s)
  -s <aryipn>  sort output according to selected field as primary key
  -S <aryipn>  sort output according to selected field as secondary key
  -t           export a textual database in aligned format
  -u --usage   print a fast usage help and exit
  -U           print output in upper case (may slower listing)
  -v --version print version and exit
  -x <aryipn>  limit search to selected field
  -y           print a note about (my personal) issue years rules and exit
 
Notes:
1. -s, -S, -x, -o options must be followed by a selector char for field:
     a   artist's name,
     r   record title,
     y   original record's issue year,
     i   CD manufacture year, if found (type cdd -y for info),
     p   publisher's name
     n   notes about the recordings (if any);
   e.g.; -sy -Sp -xa -or
2. if not specified, the default selector for primary sorting is the artist's
   name (a), the default selector for secondary sorting is the original
   record's issue year (y);
3. if pattern is followed by "+ pattern2" or "- pattern2", perform a second
   search inside last result, matching only lines that include pattern2 if +
   was used, and excluding lines that include pattern2 with if - was used; -x
   option has effect only on the first search;
4. deletion procedure started by option -d <pat> and modifying procedure
   started by option -m <pat> do not use pattern2, and must be used as the only
   option given to cdd;
5. -o selected output has precedence over -A aligned or -F framed modes;
6. if set together, the last among -A, -F and -N determines the output format;
7. if no pattern is given, cdd will silently quit;
8. the publisher's name appears only within formatted and plain modes;
9. when using --add [db] option, it must be the only option given to cdd.

Now you can understand how powerful it is. For example, here's the same output with the -n and -N option (n for numbered and N for Neutral):

$ cdd -a -n -N

1       bruce, jack     songs for a tailor      1969    1997    
2       dandy wharols   the dandy wharols       1996    1996
3       led zeppelin    bbc sessions    v.v.    1997    from studio & live    atlantic
4       pat metheny group       letter from home        1989    1989
                

or an output with the -F and -C options (F for framed and C for count)

$ cdd -F -C from

------------------------------------------------------------------------------
Artist    : led zeppelin
Album     : bbc sessions
Issued in : v.v.     CD date:  1997     Publisher:  atlantic
Notes     : from studio & live
------------------------------------------------------------------------------

Artist    : pat metheny group
Album     : letter from home
Issued in : 1989     CD date:  1989     Publisher:
Notes     :
------------------------------------------------------------------------------
2 records found.

Explore other options on your own (for instance, -o controls which field should be printed, and -x limits the search to the specified field).


As a final note, here I explain the symbols I use (appended to the issue/recording years) to define their meaning (-y option):

$ cdd -y

THE SPECIAL MARKERS AND THE SYMBOLS OF THE DATABASE
   Usually, a CD date may be the same of the CD first issue (which means the
record is rather recent) or be different if it's a reprint, maybe from an LP.
If the reprint track listing is the same of the original, having some more
bonus tracks, or being a remastering of the original tapes, nothing remarkable
happens, and the two dates are reported as they are.
   If some change arises (a track left off because it doesn't fit into the CD,
or the record is a re-recording, or a bootleg version with a different tracks
order or anyhing else), any character may be put after the issue year, e.g.
2007N. add2cdd performs this operation automatically, inserting a lower 'x'.
   When cdd finds this extra character(s), an asterisk (*) is printed after the
issue year, highlighting the 'irregular' discs.

   Other conventions I use are:
     v.v. means 'various years' - the record is typically a collection;
          it appears on the CD date meaning songs have been recorded
          in a range of (unspecified) years;
     ^^^^ means 'unknown data' (generally unavailable); it may appear in any
          field (excluding the 'Author' one, of course). It also serves as a
          memo placeholder for subsequent insertions;
     ---- means that no issue year has been found onto the cd; this symbol
          is put automatically by add2cdd when you leave 'CD date' field
          empty (hitting Return on the 'CD date' empty input line).
         
   You're free to use your own coding, of course.
   This is only my point of view.

Of course, your database may be based on different principles..

custom.data, add2cdd, peryear and reformat

custom.data is a shell script (not an executable) that contains some customizable elements: the name of the database (its whole path, in effect), the separator used to limit the record fields, the main view format, the log file name and so forth. You can change values as you like, respecting the values format; the only advice I can give you is that the separator I chose it the least probable to occur in an artist name, in a record title or in the speech used to write a note about the record, while other classic separators like : or ; may occur into a title (for instance, axis: bold as love, by Jimi Hendrix).

add2cdd is a useful script that accompanies cdd. It lets you add lines (records) to your database according to the desing principles of cdd, sorting the whole database file at the end. The separator is the same of cdd, since it's retrieved from custom.data. Here's an example of its usage (in bold the characters you type):

$ add2cdd data/whatever/dbname

You're going to add records to the database data/whatever/dbname:
press Enter in an empty 'Artist' field when you're over.

(Press Enter to begin)

Artist                 : someone
Title                  : sompthin'
Issue year (YYYY/v.v.) : 1978
Leave next field empty if you don't find any data
CD date (YYYY/empty)   : 2010
Is this issue regular (y/n)? [y]
Publisher              : nobody records
Notes                  : a vanishing episode!

Artist                 :

Database updated and sorted.
There are 47 records in the database.

Creating text version...
Done. We're through!

The text version is a textual file add2cdd creates (using option -t of cdd - an aligned database), suitable for printer or pdf. Its name is all_<dbname>_database.txt.

To delete a record, starting from version 3.0.0, you can use option -d, and to modify a record in detail, you can use option -m.

Here's the help for add2cdd:

$ add2cdd --help
add2cdd : add ordered data to the cdd database
Usage: add2cdd [OPTIONS] [filename]
Options:
  -h --help     shows this help

If a filename is given, all data will be written on it, otherwise data will be
written on the default file cd.db. After the introduction, follow the wizard.
If you type _ (underscore) from the second Artist prompt on, the Artist's name
will be set equal to the previous one. If you type Return on an empty Title
prompt, the Title will be set equal to the Artist's name. That's all.

peryear is a tool for extracting information in groups of years from the database; here's an example:

tonibin~$ peryear 1963

Database output for 1963
------------------------

YEAR 1963:
beatles              a hard day's night          1963 2009  + "a hard day's
beatles              please please me (mono)     1963 2009  box "beatles in
beatles              with the beatles (mono)     1963 2009  box "beatles in
dylan, bob           the freewheelin'            1963 ----                 
4 records found.

------------------------

Here's the help for peryear:

$ peryear --help

peryear: extract info ordered by years using cdd from target file
Usage: peryear [OPTIONS] [NNNN]
Options:
  -e             set ending year (default: current)
  -f 'filename'  use 'filename' as target database (default: cd.db)
  -s             set starting year (default: 1950)
  -h --help      show this help and exit

If NNNN is given (it must be a four-character year), starting and ending
values will be set equal to it (equivalent to -s NNNN -e NNNN), unregardless
to the values previously set with -s and/or -e options.

reformat is a tool for updating older databases (without the publisher's field); don't worry: this is not an operation you must obligatorily do; but, in order to let a correct visualization of formatted output, the publisher's field should be surrounded by both the separators, and older versions didn't do this. Updating is slow, but the process must be accomplished once only.
