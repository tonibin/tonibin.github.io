Introduction

deer is the Dartmouth Environment Elementary Renderer, a set of programs for emulating the original Dartmouth Time-Sharing Sustem (DTSS), the same on which the first BASIC compiler ran in 1964. deer at present is composed of three programs:
  • the DTSS Emulator, written in bash and working on UNIX or UNIX-like modern system (1964). This engine is named deer, of course. deer is largely adaptable because it can be set to use any BASIC or ALGOL compiler, provided you have them installed.
  • the BASIC interpreter, written in C, and emulating the version III of the Original Dartmouth BASIC language (1966). The interpreter is named dib (which means Dib Is Basic) and, as a standalone executable, may be used even outside of the deer engine.
  • The ALGOL interpreter, in the Darthmouth style (with numbered lines, only for input purposes). This emulator (1965) is called dia (which means Dia Is Algol) and, as dib, can be used as a standalone executable.
  • The FORTRAN (version IV) interpreter, written in C and emulating the GE-265 Dartmouth FORTRAN language (1966). The interpreter is named dif (which means Dif Is Fortran) and, as a standalone executable, may be used even outside of the deer engine.

Installation

The deer bash script may be executed anywhere, provided you put it into a directory contained into the PATH; the dib/dia executables, instead, before use, must be compiled and installed. I suggest the following (easy) procedure:

THE deer SCRIPT
1) Copy the package somewhere, and unpack it using tar:
$ tar zxvf deer.1.0.beta.tgz
$ cd distrib/
 2) Type:
$ make install
 to create the environment and copy the documentation. This requires no root privileges.
3) Type:
$ make maninstall
 to install the man page. If this requires root privileges, type:
$ make maninstall
: you will be requested of the root password to procede.

THE dib, dia AND dif EXECUTABLES
1) Copy the package somewhere, and unpack it using tar; for example:
$ tar zxvf dib.1.0.beta.tgz
$ cd distrib/
2) Type:
$ make install
If this should require root privileges, type
$ sudo make install
you will be asked for the root password.
This procedure will install the executable and the relative man page.
3) Now type the following:
$ sh deer --help
$ dib --help
$ dia --help
$ dif --help
to know they are correctly installed, learn the basic facts, and you're done! If you please, copy the USER directory (contained in the distrib/ directory) to your home deer directory (which is located under $HOME/.deer). There you will find many BASIC examples, ready to be run.
In any case, each package has some programs, written in the due language, that can be used into deer.
